# Sandbox Monetization Policy

The Creator Wallet is a sandbox-only view of monetization data supplied through approved YouTube OS backend API or event contracts. It does not connect to Circle, retain provider credentials, access a Global Ecosystem database, or move real money.

Eligible gross revenue is displayed using a 50/50 allocation: 50% for the creator and 50% for the platform. The backend remains authoritative for allocation, balance, compliance, and ledger state.

Sandbox withdrawal requests are simulated only. The UI presents a daily limit of $1,000, weekly limit of $5,000, and monthly limit of $20,000. KYC and AML completion are required. A request of $5,000 or more must include explicit 2FA confirmation; backend enforcement is required regardless of client-side validation.
